# 📡 Module SIGINT — BisAT
Le module SIGINT fournit les capacités d’analyse électromagnétique et de cartographie des flux.

## Capacités
- Analyse de signaux
- Extraction de patterns
- Cartographie dynamique des flux
- Détection d’anomalies EM

## Fichiers
- `analyse_signaux.py` — Analyse, filtrage, classification
- `cartographie_flux.py` — Cartographie, topologie, flux critiques

## Doctrine
SIGINT BisAT repose sur :
- Neutralité analytique
- Séparation des couches (analyse / visualisation)
- Logs systématiques
