# RTSO / OSINT
## Région Terre Sud-Ouest – Renseignement d’Environnement

Ce dossier contient les modules OSINT dédiés à la zone RTSO (Région Terre Sud-Ouest).  
Ils fournissent une vision structurée des acteurs, zones sensibles, flux, risques et sources exploitables pour une veille opérationnelle.

### Contenu
- rtso_osint.md — Vue d’ensemble OSINT RTSO
- rtso_geoint_map.md — Cartographie GEOINT RTSO
- rtso_institutions.csv — Institutions militaires, sécurité, industrie
- rtso_risks.md — Analyse des risques RTSO
- rtso_flux.md — Flux OSINT régionaux
- rtso_sources.md — Sources OSINT vérifiées
- watchlist.md — Liste de surveillance (acteurs, zones, signaux faibles)
- bisat_militaire.md — Version militaire BisAT (doctrine, classification, codes)

### Objectif
Fournir une base de renseignement ouverte pour :
- la veille stratégique,
- l’analyse territoriale,
- la détection de signaux faibles,
- la préparation opérationnelle.

### Classification interne
Document conceptuel BisAT – usage pédagogique et analytique.
