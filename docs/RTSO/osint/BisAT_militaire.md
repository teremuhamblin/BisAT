# BISAT – Module OSINT RTSO
## Région Terre Sud-Ouest – Doctrine militaire

### 1. Cadre doctrinal
Le module OSINT RTSO s’inscrit dans la doctrine BisAT :
- Surveillance des zones sensibles
- Détection des signaux faibles
- Corrélation multi-sources
- Production de renseignement exploitable
- Appui aux structures de commandement

### 2. Classification interne
Niveau : **BISAT / RT-SO / Renseignement d’Environnement**  
Diffusion : **Contrôlée – Usage conceptuel**

### 3. Zones militaires critiques
- **11e Brigade Parachutiste** – centre de gravité Terre Sud-Ouest  
- **3e RMAT** – soutien matériel  
- **17e RGP** – génie parachutiste  
- **126e RI** – infanterie  
- **1er RCP** – parachutistes  
- **BA 118 Mont-de-Marsan** – chasse  
- **BA 120 Cazaux** – entraînement aérien

### 4. Acteurs défense / industriels
- Airbus Defence & Space  
- Airbus CyberSecurity  
- CNES Toulouse  
- Thales Alenia Space  
- DGA Techniques Aéronautiques  

### 5. Signaux faibles militaires
- Activité aérienne inhabituelle (Rafale, A400M, MRTT)
- Déploiements parachutistes (11e BP)
- Mouvements logistiques RMAT
- Appels d’offres défense (Airbus, CNES, DGA)
- Recrutements accélérés (Terre / Air)

### 6. Méthodes OSINT BisAT
- **SIGINT léger** : ADS-B, radio publique  
- **SOCMINT** : flux institutionnels  
- **GEOINT** : cartographie zones sensibles  
- **INDINT** : surveillance acteurs industriels  
- **EVINT** : événements militaires / civils  
- **BUSINT** : marchés publics défense  

### 7. Codes couleur BisAT
- **Bleu RTSO** : structures militaires  
- **Rouge** : signaux faibles critiques  
- **Gris** : flux civils / sociaux  
- **Noir** : zones sensibles haute criticité  
- **Vert** : sources fiables / vérifiées  

### 8. Objectif opérationnel
Fournir une vision consolidée du RTSO pour :
- la préparation opérationnelle,
- la veille stratégique,
- la détection précoce de menaces,
- l’appui aux unités Terre du Sud-Ouest.

### 9. Mention
Document conceptuel BisAT – aucune affiliation réelle avec l’Armée de Terre.
