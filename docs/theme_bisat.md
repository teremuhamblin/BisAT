# 🎨 Charte graphique BisAT

Le thème BisAT est conçu comme une identité visuelle **militaire cyber‑défense**, sobre, froide, opérationnelle.

---

## 1. Palette de couleurs

### Couleurs principales
- **Bleu profond opérationnel**  
  Hex : `#1e3a8a`  
  Usage : barres, titres, blocs tactiques, fond de modules.

- **Gris acier / nuit**  
  Hex : `#0a0f1c`  
  Usage : fonds principaux, arrière‑plans, zones critiques.

- **Rouge tactique**  
  Hex : `#e11d48`  
  Usage : alertes, liens importants, accents, surlignage.

### Couleurs secondaires
- **Gris clair technique**  
  Hex : `#9ca3af`  
  Usage : textes secondaires, bordures, annotations.

- **Vert validation**  
  Hex : `#10b981`  
  Usage : succès, validation, états OK.

---

## 2. Typographie

### Police principale
- **Sans‑serif robuste** : `system-ui`, `Segoe UI`, `Roboto`, `Arial`
- Style : net, lisible, sans fioritures.

### Hiérarchie
- Titres (H1/H2) : majuscules ou semi‑majuscules, gras.
- Sous‑titres (H3/H4) : gras, taille moyenne.
- Corps de texte : régulier, lisible, contrasté.

---

## 3. Iconographie & formes

- Formes privilégiées : **boucliers, cercles, blocs rectangulaires**, lignes nettes.
- Pas de courbes décoratives inutiles.
- Symboles : antennes (SIGINT), cerveau / silhouette (HUMINT), bouclier / cible (CyberOps), nœuds / liens (Fusion), carte / grille (Atlas).

---

## 4. Usage par modules

- **SIGINT** : bleu profond + rouge tactique, icônes de signaux, ondes.
- **HUMINT** : bleu + gris, silhouettes, profils, diagrammes.
- **CyberOps** : boucliers, cibles, cercles concentriques, rouge tactique plus présent.
- **Fusion** : nœuds, graphes, intersections, double‑cercles.
- **Atlas** : cartes, grilles, coordonnées, lignes horizontales/verticales.

---

## 5. Règles d’interface (UI)

- Fond principal : `#0a0f1c`
- Blocs : `#1e3a8a` avec bordure fine `#9ca3af`
- Boutons primaires : fond `#1e3a8a`, texte blanc, hover `#e11d48`
- Boutons secondaires : fond `#0a0f1c`, bordure `#9ca3af`, texte `#e5e7eb`
- Liens : texte `#e11d48`, soulignement léger au survol.

---

## 6. Ton & style

- Ton : **militaire, froid, professionnel**, jamais ludique.
- Pas de dégradés flashy, pas de couleurs pastel.
- Priorité : lisibilité, contraste, structure.

---
