# Mentions Légales — BISAT
**Document conceptuel — Usage pédagogique — Non affilié**

BISAT est une création conceptuelle inspirée des structures françaises de cyberdéfense.  
Aucune affiliation réelle avec :
- Armée de Terre  
- COMCYBER  
- DGA  
- DIRISI  
- Institutions militaires ou gouvernementales

- Ce projet ne constitue pas un outil opérationnel réel.  
- Aucune donnée sensible, classifiée ou réelle n’est utilisée.

- Usage pédagogique, documentaire, expérimental.  
- Interdiction d’utilisation dans un cadre opérationnel réel.
