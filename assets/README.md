# 📦 Dossier assets/ — BisAT

Le dossier `assets/` regroupe l’ensemble des ressources visuelles, graphiques et techniques du projet BisAT.  
Il constitue la base de l’identité visuelle et documentaire du Bureau d’Intelligence Souterraine.

---

## 📁 Structure

### `badges/`
Insignes militaires, écussons, identités visuelles tactiques.

Contenu :
- `bisat_badge.svg` — Badge officiel BisAT
- Variants futurs : SIGINT, HUMINT, CyberOps, Fusion, Atlas

### `schemas/`
Schémas techniques, architectures, flux, topologies.

Contenu :
- `architecture_bisat.svg` — Architecture globale du système
- Schémas futurs : pipelines, matrices, cartographies

### `logos/`
Logos institutionnels, versions vectorielles, branding BisAT.

Contenu :
- `logo_bisat.svg` (à venir)
- Variants monochromes / tactiques

---

## 🎨 Standards graphiques

- **Format privilégié : SVG**
- **Palette BisAT :**
  - Bleu profond (#1e3a8a)
  - Gris acier (#0a0f1c)
  - Rouge tactique (#e11d48)
- **Style : militaire, cyber‑défense, géométrique**
- **Lisibilité maximale** (polices épaisses, contrastes forts)

---

## 🛠️ Bonnes pratiques

- Toujours privilégier le vectoriel
- Nommer les fichiers de manière explicite
- Organiser par sous‑dossiers thématiques
- Ne jamais mélanger logos, badges et schémas
